# MarketPilot AI

## Project scope

MarketPilot AI is a high-fidelity, clickable frontend prototype for an academic AI Economy presentation. Phase 1 includes the public landing page, demo sign-in, seller overview, and product catalog. Phase 2 includes the five-step product wizard, full product details, and simulated AI analysis and results. Phase 3 includes marketplace research, comparison, market intelligence, and pricing. Keep entered product data, suggestions, and pricing plans in React state. Use clearly labeled placeholders for later screens until those phases are requested.

## Design system

- Use Inter and a professional, minimal SaaS visual style.
- Use navy #0F172A for primary text, blue #2563EB for primary actions, purple #7C3AED for AI, and green #059669 for success.
- Use #F8FAFC for the application background and #FFFFFF for cards.
- Keep spacing, typography, borders, and shadows consistent. Support desktop, tablet, and mobile. Use visible focus states and accessible component labels.

## Technical stack

React, TypeScript, Vite, Tailwind CSS, Lucide React, React Router, and Recharts. Prefer small, reusable components and simple React state. Use shadcn/ui where it adds value without extra complexity.

## Working rules

- Keep AI analysis, marketplace feeds, estimated revenue, and publishing simulated and explicitly labeled. Use fictional sample data.
- Do not add backends, databases, actual authentication, AI models, marketplace APIs, or cloud infrastructure.
- Keep visible actions functional with navigation, a demonstration dialog, or simple local state. Never request real credentials.
- Use original or permitted imagery with a local fallback.
- Preserve unrelated files, run npm run build, and leave commits and pushes to the user unless asked.
